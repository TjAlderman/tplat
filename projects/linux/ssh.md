# SSH

SSH is the standard protocol for secure remote command execution and administration on Unix-like systems.

## Overview

- Provides encrypted remote access without a GUI
- Is widely installed and efficient on low-resource systems
- Commonly used for administration, automation, and file transfer workflows

## Reference

```bash
ssh user@host
```

## Mental Model

- SSH replaces insecure remote login methods with an encrypted channel
- It is the default way to manage many remote Linux systems
