# System Management

System management covers the everyday tasks used to keep a Linux host running: users, services, scheduling, and maintenance.

## Overview

- Most work is done from the command line
- Administration usually combines access control, service control, and automation
- The main tools are spread across several focused subtopics

## Reference

| Area | Focus |
| --- | --- |
| User management | Accounts, groups, and privilege elevation |
| Service management | Start, stop, inspect, and enable services |
| Scheduling | Timers, cron jobs, and recurring work |
| Maintenance | Updates, cleanup, and backups |

## Mental Model

- System administration is mostly about controlling who can do what, what runs, and when it runs
- The smaller the tool, the easier it is to automate and reason about
